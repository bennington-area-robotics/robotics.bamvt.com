# Kickoff artwork

The banner is the unmodified `canopy_ftc_biobuzz_social_fb_post.png` from
[FIRST's official season brand downloads](https://www.firstinspires.org/resources/library/season-brand-downloads).
The social image uses the yellow `canopy_ftc_biobuzz_social_fb_post_blank.png`
from the same [social template package](https://www.firstinspires.org/hubfs/web/brand/season/2027/downloads/first-biobuzz-posts-templates.zip).

FIRST, FIRST Tech Challenge, FIRST CANOPY, BIOBUZZ, and the associated logos
belong to their respective owners. See the
[BIOBUZZ style guide](https://www.firstinspires.org/hubfs/web/brand/season/2027/downloads/ftc-biobuzz-styleguide.pdf).

The social image was prepared with the built-in image generation tool using
the yellow template as the edit target and this prompt:

> Edit this yellow BIOBUZZ social template, preserving the entire background and all existing top logos and icon exactly without cropping. Only add centered dark teal sans-serif text in the blank area below the logos. Landscape approximately 1.9:1. Exact lines: SEASON KICKOFF / Saturday, September 12, 2026 / 11:30 AM • Game reveal at noon / Manchester Community Library / Manchester Center, Vermont / Co-hosted by / Bennington Area Robotics & Manchester Machine Makers. Largest headline, clear date/time, smaller co-host credit, generous margins, legible professional typography. No other additions. Output PNG.
