# At work in the shop

Students are building prototypes for collecting, storing, and launching game
pieces, while others test code for movement and tracking on the practice field.

{% include figure.html src="https://assets.bamvt.com/robotics.bamvt.com/blog/at-work-in-the-shop/images/build-table.jpg" alt="Students and a mentor working along a build table covered with aluminum channel, intake wheels, belting, and hand tools, below a Cookie Clickers banner" caption="Prototype assembly at the Cookie Clickers build table." %}

## Prototypes

A prototype is a quick build that tests one idea before the team commits to a
design. Collection, storage, and launching each get their own prototypes, so
students can compare approaches and see what works on the field. Experienced
members work alongside newer students as they assemble channel, shafts, and
wheels.

{% include figure.html src="https://assets.bamvt.com/robotics.bamvt.com/blog/at-work-in-the-shop/images/prototype-assembly.jpg" alt="A student fastens an aluminum channel assembly with a screwdriver while an older teammate in safety glasses watches" caption="An experienced teammate works with a newer student on a prototype assembly." %}

## Code on the Field

While the build table fills up, the practice field is in use for software.
Students run and adjust code for movement and tracking on a working robot, so
programming does not wait for the new mechanisms to be finished.

{% include figure.html src="https://assets.bamvt.com/robotics.bamvt.com/blog/at-work-in-the-shop/images/practice-field.jpg" alt="A coach talks with a student beside the practice field while another student works on a robot on the field and others build at a bench" caption="Testing on the practice field while prototyping continues at the bench." %}
